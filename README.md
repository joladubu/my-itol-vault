# ITOL Vault

A responsive digital journal for recording, organising and revisiting personal reflections.

## Project Goals

- Create a home page featuring the five most recent entries.
- Allow users to create and save journal entries.
- Display all saved entries in a journal archive.
- Persist entries using browser localStorage.
- Provide a responsive layout for desktop and mobile devices.

## Technologies

- HTML
- CSS
- JavaScript
- Browser localStorage
